# intervals

Short duration parsing and rendering.

The documentation for this package lives in the docstrings of
`intervals/core.py`, and is the only description of the API that ships. Each
public function documents its parameters with `:param:`, its result with
`:returns:`, and carries a worked example.

Those examples are executable: they are written in doctest form and are run as
part of the project's checks, so an example that disagrees with the code is a
defect in the documentation.

The unit table and the arithmetic shared by the parser and the formatter live in
`intervals/units.py`.
